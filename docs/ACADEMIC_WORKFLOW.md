# AI-driven Academic Research 工作流

小允翻译把“看懂一句话”延伸为“组织一个研究项目”。下面是一套适合论文、综述和教材的本地工作流。

## 1. 先建立项目

在论文库左侧点击“新建项目”，可按以下方式组织：

-   课题：`代谢通量与热力学`
-   输出目标：`博士开题综述`
-   方法：`同位素示踪`
-   阅读批次：`2026-07 待读`

一篇文献可以加入多个项目。项目用于研究范围，标签用于状态和属性，两者不互相替代。

推荐标签：

-   待读 / 精读 / 已复现
-   核心证据 / 反例 / 方法学
-   图表重要 / 需要核验 / 可引用

## 2. 导入时选择“论文”或“书籍”

### 论文

适用于研究论文、预印本和技术报告。文本索引完成后生成并保存：

-   全文概要；
-   研究问题；
-   方法；
-   主要发现；
-   局限；
-   关键术语及原文页码。

再次打开时直接读取已有结果，不必每次重新生成。

### 书籍

适用于教材、专著和长篇扫描 PDF。书籍使用独立的章节工作流：

-   优先读取 PDF 自带目录；
-   没有目录时分析目录页与标题结构；
-   校准印刷页码与 PDF 物理页码；
-   点击章节正确跳转；
-   按需生成章节摘要和关键术语；
-   章节结果写入本地数据库并复用。

对于数百页文档，优先只处理当前阅读章节，避免一次把整本书送入模型。

## 3. 读前：先看证据地图

论文概要适合快速判断“是否值得精读”，但不应替代原文。

建议顺序：

1. 阅读研究问题；
2. 检查研究方法；
3. 浏览主要发现；
4. 打开局限；
5. 点击关键术语的页码回到原文；
6. 判断是否加入精读项目。

模型生成内容需要与摘要、方法和图表交叉核验。

## 4. 阅读中：划词即译

在 PDF 中拖选文字，松开后翻译浮窗会在不遮挡选区的位置出现。翻译请求包含：

-   当前选区；
-   选区前后文；
-   论文标题；
-   已保存的相关术语；
-   简短论文概要。

这些上下文只帮助消歧，模型仍只翻译选区。这样可让 `flux` 在代谢建模中稳定译为“通量”，而不是机械翻成“流动”。

浮窗操作：

-   **复制**：复制格式化译文；
-   **朗读**：使用 Windows 本地语音；
-   **高亮**：保存彩色高亮；
-   **摘抄**：保存原文和页码；
-   **笔记**：保存笔记、颜色和标签；
-   **解释**：基于当前选区和页面证据解释。

选中单词或短词组时，软件会进入词典模式，给出音标、词性、多重词义、当前语境义和领域说明。

## 5. 公式和 Markdown

普通翻译与论文翻译都会保留：

-   `**粗体**`、列表等 Markdown；
-   `$Sv = 0$`、`\(\Delta_r G'\)` 等 LaTeX；
-   单位、数字、上下标和变量；
-   文献引用标号。

公式输出由 KaTeX 渲染。若 PDF 文本层把复杂公式拆碎，可使用 Ctrl+E 框选公式图像，让多模态模型重新识别。

## 6. 扫描件与长文档

扫描 PDF 的“可见图像”和“可选文字”是两层：

-   页面能显示但不能选字：使用 OCR；
-   页面空白：先确认 PDF 在 Edge 中可打开，再检查是否为特殊编码；
-   当前版本内置 PDF.js WASM，支持常见 JBIG2 扫描页。

处理建议：

1. 先对当前页 OCR，确认质量；
2. 需要全文检索时再启动整篇 OCR；
3. 后台 OCR 可暂停和取消；
4. 长书按页索引，不阻塞阅读；
5. 公式、表格和图注仍需人工核验。

## 7. 建立可回溯的笔记

高质量笔记至少包含：

-   原文引文；
-   页码；
-   你的判断，而不只是模型摘要；
-   颜色或标签；
-   它支持或反驳的研究问题。

小允翻译的标注保存页码、引文、前后文、文本偏移和矩形坐标，重新打开或缩放后用于重新锚定。标注不会写回原 PDF。

支持 `Ctrl+Z` 撤销最近一次高亮或笔记操作；也可以在摘录列表或文中标签上删除已有记录。

## 8. 使用引用关系

引用页会尝试从参考文献和正文引用中匹配文献库内已有论文，并区分：

-   当前论文引用了哪些库内论文；
-   哪些库内论文引用了当前论文。

这是本地启发式匹配，不等同于 Crossref、OpenAlex 或出版商数据库。标题缺失、扫描 OCR 错误、引用格式异常时可能无法建立关系；请把它当作导航线索，而不是完整引文计量结果。

## 9. 论文问答的证据规则

适合的问题：

-   “作者为什么选择这个实验设计？”
-   “这个结论由哪一页的哪些证据支持？”
-   “所选公式中的变量分别是什么？”
-   “这一节与前一节的假设有什么关系？”

不适合直接相信的问题：

-   原文没有数据却要求模型给出精确数值；
-   要求跨多篇论文得出未经核验的结论；
-   将模型解释当作临床、法律或安全决策。

论文问答应返回页码和原文引文。证据不足时，正确行为是拒答或说明缺少证据。

## 10. 推荐的完整闭环

1. 创建项目；
2. 导入论文或书籍；
3. 用概要筛选；
4. 进入原文精读；
5. 划词翻译并核对术语；
6. 高亮关键证据；
7. 写下自己的笔记并打标签；
8. 用引用关系扩展阅读；
9. 回到项目视图整理证据；
10. 定期备份本地文献库。

所有模型结果都应服务于阅读，而不是替代阅读。
