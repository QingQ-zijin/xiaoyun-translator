# Pot 译文 Markdown 与 LaTeX 渲染设计

## 目标

仅增强译文结果卡片，使模型返回的 Markdown 强调、列表、代码和 LaTeX 公式按排版结果显示。源文区域继续使用可编辑文本框。复制、历史记录、朗读、回译和收藏仍消费模型返回的原始译文，不受展示层转换影响。

## 非目标

- 不渲染源文区域。
- 不执行模型返回的原始 HTML。
- 不改变非字符串词典结果的现有结构化视图。
- 不引入完整 MathJax 运行时，也不扩展为通用文档编辑器。

## 技术方案

采用现有 `react-markdown`，新增 `remark-math`、`rehype-katex` 和 `katex`。译文字符串不再放入只读 `textarea`，而是传给独立的 `FormattedTranslation` 组件。`\(...\)` 与 `\[...\]` 由自定义 remark/micromark 扩展在同一次 Markdown 解析中生成数学节点。

组件职责：

1. 接收原始译文和字体大小。
2. 纯函数只去除流式输出末尾的单个 `_` 光标标记，不改写 Markdown 原文。
3. 使用 ReactMarkdown 单次解析 Markdown：`remark-math` 处理 `$`、`$$`，自定义扩展处理 legacy TeX 分隔符，KaTeX 渲染数学节点。
4. 使用紧凑样式控制段落、列表、代码块和块级公式间距，使其适应当前窄窗口。
5. 禁用原始 HTML；KaTeX 使用 `trust: false` 与非抛错模式。

`TargetArea` 中的 `result` 始终保留原值。展示组件只读取它，不覆盖它，确保复制、数据库历史、TTS、回译、重试和收藏行为不变。

## 流式输出与容错

Ollama 流式翻译会不断刷新部分字符串，并在临时结果末尾追加 `_`。展示归一化只移除最后一个明确的光标标记，不删除正文中的下划线。legacy TeX 直接在 Markdown AST 管线中解析，避免每个流式分片重复解析两次。

流中可能暂时出现未闭合的 `**`、反引号或数学分隔符。渲染器必须允许这种中间状态：

- 不执行 HTML。
- KaTeX 解析错误不向上抛出，错误片段以可读文本显示。
- 后续流片段补齐语法后，React 根据新字符串自然重渲染。
- 普通美元金额只有成对且符合数学分隔符规则时才进入数学解析；prompt 同时要求金额使用转义美元符号。

## Prompt 设计

更新当前 Ollama 系统提示词，并同步修改源码中的 Ollama 默认提示词。新增约束：

- 只输出译文，不增加解释或 Markdown 代码围栏。
- 保留源文已有的强调；需要强调时只使用 `**粗体**`，不输出 HTML 标签。
- 行内公式统一使用 `$...$`，块级公式统一使用 `$$...$$`。
- 公式内部的变量、运算符、上下标、单位结构和 LaTeX 命令不得翻译；仅翻译公式外的自然语言。
- 不把普通货币金额当作公式，美元符号写为 `\$`。
- 不为了展示效果凭空增加粗体或公式。
- 保留引号符号与结构，但翻译引号内的自然语言。
- 专名使用目标语的通行译名或准确音译，不在英文译文中保留未翻译中文。

Prompt 是输出规范，前端渲染器仍需兼容模型偶尔返回的 `\(...\)`、`\[...\]`。

## 安全边界

- ReactMarkdown 不启用 `rehype-raw`，原始 HTML 被跳过且不执行。
- KaTeX 禁止受信任命令和外部资源能力。
- Markdown 链接和图片只渲染为不可点击文本，不导航也不加载远程资源。
- 代码块和行内代码保持文本语义，不执行其中内容。

## 测试与验收

先以 Node 内建测试为纯预处理函数建立失败用例，再实现功能。至少覆盖：

1. `**关键结论**` 保留为 Markdown，最终构建可渲染为粗体。
2. `$\le 10$` 保持行内数学格式。
3. `\(x^2\)` 在 AST 中生成行内数学节点。
4. `\[x^2\]` 在顶层、引用和列表内生成保持容器结构的块数学节点。
5. 流式末尾 `_` 被清除，正文中的 `snake_case` 不受影响。
6. 未闭合数学分隔符不会导致异常。
7. 原始 HTML 不被执行。

验证顺序：

- 针对性 Node 测试。
- Vite 生产构建。
- Rust `cargo check --locked`，确认桌面应用集成未破坏。
- Tauri 窗口实际验证：粗体、行内公式、块公式、普通美元符号、流式逐步更新。
- 核对复制按钮仍得到原始 Markdown/LaTeX 文本。

## Ctrl+D 延迟优化

- 翻译 WebView 关闭时改为隐藏并复用，避免每次 Ctrl+D 冷启动。
- Windows 前台模式在阻塞取词前以 `SW_SHOWNOACTIVATE` 显示，取词完成后再聚焦；后台隐藏模式始终不显示、不抢焦点。
- 对明确的长英文、简中、日文和韩文先给保守的本地语言结果以启动翻译，远程检测仅在请求仍有效时校正。
- 用户主动隐藏会同步废弃语言检测、翻译与回译旧回调；配置的自动隐藏仍允许后台完成。
- 常驻 WebView 对服务实例配置的加载和变更使用统一代次，新模型、地址或 Prompt 不会被旧快照覆盖。

## 迁移策略

无数据迁移，直接替换字符串译文的展示组件。现有历史记录无需转换，重新打开时仍可由新组件渲染。当前用户的 Ollama prompt 会先备份，再原位更新。
